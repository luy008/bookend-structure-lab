# V017 · 실제 Blender 제품 구조 실험실

원본 Blender 제품의 69개 부품을 보여 주는 정적 웹사이트입니다.
처음 열면 전체 제품 3D가 표시되며 드래그 회전, 확대, 정면·측면 보기를 지원합니다.
북엔드·독서대·슬라이더 탭과 3–5 kg 알루미늄 경량안 비교를 포함합니다.

## GitHub Pages

저장소의 Settings → Pages에서 main 브랜치의 /(root)를 게시 폴더로 선택합니다.
이 폴더의 파일을 main에 커밋하면 GitHub Pages가 변경 사항을 자동 게시합니다.
별도 빌드나 패키지 설치가 필요 없으며 모든 웹 자산은 상대경로를 사용합니다.

## 계산 범위

경량안은 6061-T6 알루미늄 가정(E=68.3 GPa, 밀도 2,700 kg/m³,
비교 항복강도 240 MPa)에 대한 부재 계산입니다. 응력에는 하중 계수 2.0을 적용합니다.
3–5 kg 책 하중에 대한 지주·브리지·수납 데크 계산과 독서판 휨 해석을 포함합니다.
미수렴한 독서판 최대 응력은 표시하지 않습니다.
관절·잠금장치·체결부·베이스 포켓의 실제 내하중은 검증 전이며,
표시된 부재 결과로 완제품의 5 kg 허용 하중을 확정하지 않습니다.
원본 형상과 경량화 제안은 화면에서 구분하며 원본 Blender 파일은 수정하지 않았습니다.
